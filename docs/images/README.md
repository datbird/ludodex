# Screenshots and diagrams

The README references these by name. Drop them in and they appear — nothing else to
wire up.

| file | what it should show | notes |
|---|---|---|
| `library.png` | the main library grid, full of real box art | The hero shot. Wide (~1400px), dense, obviously a real collection rather than five test rows. |
| `detail.png` | one game's detail page — matched providers, media, attributes | ~700px wide. Pick a game with good art and several sources. |
| `wand.gif` | the wand running on a badly-matched game and correcting it | Short loop, ~6–10s. Show the before state long enough to read it. |
| `platforms.png` | the same game across several platforms | The per-platform-entry idea is the hardest thing to explain in words — this is the picture that does it. |

## Guidelines

- **Dark theme**, since that's what the app looks like and what reads well on GitHub.
- **Crop out the browser chrome.** No tabs, no URL bar, no OS taskbar.
- **Retina/2x** if you can — GitHub scales them down and they stay crisp.
- **Real data.** A screenshot of five placeholder games undersells it more than no
  screenshot at all.
- Keep each file under ~2 MB; GIFs under ~5 MB, or they stall on load.

## Anything else

Extra images are welcome — add them here and reference them from the relevant doc rather
than the README, which should stay short.
